*   **`about.md`**: A three-word personal description.
*   **`pelican.svg`**: A unique SVG illustration.
*   **`restaurant.json`**: A restaurant recommendation for Chennai.
*   **`prediction.json`**: A forecast for the Fed Funds rate in December 2025.
